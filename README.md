AI-ассистент для обработки внутренних обращений сотрудников в IT-службу поддержки.

## Проблема

Сотрудники обращаются в поддержку по телефону или через email. Человек вручную регистрирует заявку и распределяет её по отделам. Это медленно: обработка занимает много времени, после эскалации скорость не увеличивается, а неправильно оформленную заявку нельзя переработать без потери истории.

## Решение

Чат-ассистент принимает обращение в свободной форме, классифицирует его автоматически и либо отвечает сам, либо формирует заявку и направляет в нужный отдел — одним кликом от пользователя.

## Архитектура
Три независимых сервиса общаются через REST API:
Frontend — два интерфейса: чат для сотрудника и дашборд для агента поддержки.
Backend (этот репозиторий) — FastAPI сервер. Принимает запросы от фронтенда, сохраняет данные в PostgreSQL, вызывает AI Service для классификации. Единственный сервис с доступом к базе данных.
AI Service — отдельный сервис на Mistral. Принимает текст обращения, возвращает категорию, приоритет и черновик ответа.


## Безопасность и данные

- **Сессии сохраняются** — история диалога доступна пользователю при повторном входе
- **Данные не утекают** — все данные хранятся на серверах заказчика (self-hosted)
- **Внешние AI API** — запросы к Mistral содержат только текст обращения без персональных данных
- **JWT авторизация** — каждый запрос проверяет токен, роли: `user`, `agent`, `admin`
- **Пароли** — хранятся только в виде bcrypt-хэша, оригинал нигде не сохраняется


## Метрики системы (таблица ai_logs)

С первого дня работы система собирает данные для оценки эффективности:
- % решено AI
- Доля обращений закрытых без участия агента
- Точность классификации
- % правильно определённых отделов
- Среднее время ответа
- От обращения до решения
- Принятые черновики 
- % ответов AI принятых агентом без правок
